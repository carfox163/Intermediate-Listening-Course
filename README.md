# 发展汉语 · 中级听力 II · 听力训练（网络课件）
<https://intermediate-listening.netlify.app/>

发展汉语（第2版）中级听力（Ⅱ）The Intermediate Listening Course (Ⅱ), with altogether 30 lessons, is suitable for college sophomores or learners with equivalent Chinese proficiency.
基于《发展汉语（第二版）中级听力 II》制作的**单文件交互式网页课件**。把教材的课文、词语与练习整合到一个 `index.html` 中，用浏览器即可打开学习，无需联网下载资源、无需安装任何软件。

> 说明：本课件**不使用教材原配套音频**，改用浏览器内置的微软神经语音（TTS）来朗读课文与词语；练习题默认留空，点击空白处即可显示答案。

---

## 一、主要特性

- **单文件、零外链**：所有样式、脚本与课文数据都内嵌在 `index.html` 中，可直接双击用浏览器打开，也可整体拷贝到任意位置或部署到静态网站。
- **带 Logo 的目录首页**：首页以卡片形式列出全部课文，并显示每课的生词数、课文段数、练习组数等统计；点击卡片进入对应课文。
- **左侧导航栏（可收起）**：默认展开，列出 30 课与「本课目录」；点击左上角 `☰` 可收起/展开；点击左上角品牌区可随时返回目录首页。
- **文字点读**：课文、词语、练习题干中的文字均可**点击朗读**（再次点击同一处可停止）。
- **悬浮「显示全部答案」按钮**：一键展开/收起本课所有练习答案。
- **畅所欲言 · 连读**：该模块提供「连读」按钮，可按顺序连续朗读本模块全部条目，按钮变为「停止」时可中止。
- **学习词语 · 连读生词**：一键连续朗读本课生词。
- **课文 · 整篇连播**：点击「整篇连播」按顺序朗读全文，旁边配有「停止」按钮；底部播放条显示当前段落进度。
- **练习默认留空、点空白显答案**：练习题答案默认隐藏，点击题目空白处（或答案区）即可显示/隐藏参考答案。
- **多题型支持**：连线、填空、选词、多选、判断、选择、排序、填表、句式练习等，并按教材标注「答案据课文」等提示。

## 三、使用方法

1. **打开**：双击 `index.html`，或拖入浏览器窗口（推荐使用 Edge / Chrome）。
2. **进入课文**：在首页点击某课卡片，或在左侧导航选择课次。
3. **朗读**：单击任意可读文字即可朗读；课件自动按中/英文选择对应语音（中文默认「云扬 / yunyang」，英文默认「Sonia」）。
4. **看答案**：点击练习题的空白区域显示参考答案；或点击右下角悬浮的「显示全部答案」一次性展开。
5. **连续播放**：
   - 畅所欲言 / 学习词语：点「连读 / 连读生词」连续朗读，再点一次停止。
   - 课文：点「整篇连播」朗读全文，点「停止」中止。
6. **返回首页**：点击左上角品牌 Logo 或「目录首页」。

## 四、语音朗读说明（重要）

朗读依赖浏览器的 **Web Speech API（SpeechSynthesis）**，语音由操作系统/浏览器提供：

- **中文**默认使用微软神经语音 **云扬（yunyang）**；**英文**默认使用 **Sonia**。若当前环境没有这两个声音，课件会自动回退到系统中可用的最佳中/英文语音。
- 这些神经语音在 **Windows 10/11 + Edge / Chrome** 上最为齐全；**首次使用可能需要联网**以加载在线神经语音。
- 若浏览器不支持朗读，顶部语音标签会显示「浏览器不支持朗读 / 未检测到语音」，此时文字点读功能不可用，但课程内容、练习与答案显示均不受影响。
- 朗读语速可在课件内调节（`state.rate`）。

## 五、课程结构

- **课数**：全套 **30 课**（第 1 课《还是回来好》至第 30 课《导盲犬和他的主人》）。
- **每课五大模块**：
  1. 畅所欲言（Warm-up）
  2. 学习词语（Key Words）
  3. 课文（Text）
  4. 理解练习（Comprehension，部分课含）
  5. 练习（Exercises）
- **练习总量**：全册共 **223 组**练习，覆盖多种听力/理解题型。

## 六、技术说明

- 纯前端实现，无后端、无第三方 CDN 依赖，无任何外部网络请求（除朗读所需的系统语音外）。
- 样式与交互全部写在单文件内，方便分发、备份与二次开发。
- 课程内容数据（`DATA`）与界面逻辑分离，改内容只需编辑内嵌 JSON。

## 七、兼容性与注意事项

- 推荐使用 **PC Edge浏览器新版本**；旧版浏览器可能缺少所需语音或渲染异常。
- 以 `file://` 方式直接打开即可运行；若部署到服务器，任意静态托管均可。
- 本课件为教学辅助材料，课文与练习内容整理自《发展汉语（第二版）中级听力 II》，版权归原出版社与作者所有，仅供学习使用。
